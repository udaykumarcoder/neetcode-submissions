Core idea

Each group of four cells rotates in a cycle: bottom-left → top-left → top-right → bottom-right → bottom-left.

Save the top-left value first because it gets overwritten. Put that saved value into the top-right cell at the end.

Important: range(r-l) excludes the last corner offset so that a group of four corners is not processed twice. After one layer, shrink the boundaries: l += 1, r -= 1.
