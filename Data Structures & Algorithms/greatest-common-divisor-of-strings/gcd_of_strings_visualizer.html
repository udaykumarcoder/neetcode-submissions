Core idea

Try prefix lengths from largest to smallest. A length L is possible only when both string lengths divide evenly by L, and repeating the same prefix reconstructs both complete strings.

Correction to the screenshot: isDivisor expects an integer length. The call must be isDivisor(L), not isDivisor(str1[:L]). Passing a substring makes the modulo operation fail with a TypeError.
