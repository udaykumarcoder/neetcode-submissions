Key mental model

When we find an original zero at (r,c), we mark its column at matrix[0][c] and its row at matrix[r][0]. Then we use those markers to zero inner cells.

rowZero separately remembers whether the original first row had a zero. The top-left cell is reserved to indicate whether the first column needs zeroing.

Order matters: process inner cells first, then the first column, then the first row. Otherwise, writing zeros into marker cells too early could destroy information we still need.
